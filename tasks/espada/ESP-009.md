# ESP-009 — Minimal standard library

Status: IN PROGRESS
Baseline: `4b0705a7fc162ceb57eaf604890eb16b98fb4a0c` (`main` after ESP-008).
Dependencies: ESP-008 complete; verified Core IR and transitional C execution available.
Date: 2026-09-19 UTC.

## Observable objective

Provide the deterministic collections, text/bytes utilities, result types,
arena-backed storage, paths, bounded compiler-host file access, and minimal
serialization needed to implement the lexer/parser/compiler in Argorix Core.
The collection and serialization logic must be `.argx` code executed through
the Core toolchain, not Rust library wrappers.

## Implementation slices

1. Freeze the public APIs, deterministic ordering rules, limits, and stable
   error/result types in `spec/core/stdlib.md`.
2. Lower the approved `Buffer<T>` and `Arena<T>` primitives through verified
   IR to the C1 runtime, including checked growth, stale handles, release, OOM,
   and resource limits.
3. Implement specialized Core `.argx` modules for bytes/text, vectors,
   deterministic maps, results, paths, and the JSON subset actually consumed
   by the compiler bootstrap.
4. Add a typed compiler-host boundary for bounded package reads/build writes;
   canonical roots and capabilities are supplied by the driver, never by
   source strings or ambient authority.
5. Execute positive and adversarial fixtures through the ESP-008 C runner and
   record memory ceilings and deterministic outputs.

## Acceptance criteria

- [ ] Public stdlib APIs and stable error/limit behavior are documented.
- [ ] Collection and serialization algorithms live in `.argx`; Rust is only
      the explicitly transitional frontend/IR emitter.
- [ ] Bytes/text, vector, deterministic map, result, arena, path, bounded file,
      and required serialization fixtures compile and execute.
- [ ] Invalid UTF-8, integer/size overflow, duplicate keys, invalid/stale
      handles, traversal/out-of-root paths, oversized inputs, OOM, and resource
      limits fail with exact deterministic results or traps.
- [ ] Map iteration and serialized output are deterministic across repeated
      gcc/clang executions.
- [ ] Compiler-host capabilities do not leak into the agent-runtime profile;
      no shell, arbitrary process, ambient environment, or unrestricted path
      access is introduced.
- [ ] Workspace regression, formatting, Clippy, native C execution, and CI pass.
- [ ] Evidence distinguishes this standard-library milestone from a lexer,
      parser, self-hosted compiler, native backend, or full Rust independence.
