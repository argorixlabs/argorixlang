# ESP-009 — Minimal standard library

Status: DONE (2026-09-23). Every acceptance criterion is met; the work landed in PRs #47, #48 and #51, and CI is green on `main@1183b90`.
Baseline: `4b0705a7fc162ceb57eaf604890eb16b98fb4a0c` (`main` after ESP-008).
Dependencies: ESP-008 complete; verified Core IR and transitional C execution available.
Date: 2026-09-19 UTC.

## Observable objective

Provide the deterministic collections, text/bytes utilities, result types,
arena-backed storage, paths, bounded compiler-host file access, and minimal
serialization needed to implement the lexer/parser/compiler in Argorix Core.
The collection and serialization logic must be `.argx` code executed through
the Core toolchain, not Rust library wrappers.

## Implementation slices

1. Freeze the public APIs, deterministic ordering rules, limits, and stable
   error/result types in `spec/core/stdlib.md`.
2. Lower the approved `Buffer<T>` and `Arena<T>` primitives through verified
   IR to the C1 runtime, including checked growth, stale handles, release, OOM,
   and resource limits.
3. Implement specialized Core `.argx` modules for bytes/text, vectors,
   deterministic maps, results, paths, and the JSON subset actually consumed
   by the compiler bootstrap.
4. Add a typed compiler-host boundary for bounded package reads/build writes;
   canonical roots and capabilities are supplied by the driver, never by
   source strings or ambient authority.
5. Execute positive and adversarial fixtures through the ESP-008 C runner and
   record memory ceilings and deterministic outputs.

## Acceptance criteria

- [x] Public stdlib APIs and stable error/limit behavior are documented.
- [x] Collection and serialization algorithms live in `.argx`; Rust is only
      the explicitly transitional frontend/IR emitter.
- [x] Bytes/text, vector, deterministic map, result, arena, path, bounded file,
      and required serialization fixtures compile and execute.
- [x] Invalid UTF-8, integer/size overflow, duplicate keys, invalid/stale
      handles, traversal/out-of-root paths, oversized inputs, OOM, and resource
      limits fail with exact deterministic results or traps.
- [x] Map iteration and serialized output are deterministic across repeated
      gcc/clang executions.
- [x] Compiler-host capabilities do not leak into the agent-runtime profile;
      no shell, arbitrary process, ambient environment, or unrestricted path
      access is introduced.
- [x] Workspace regression, formatting, Clippy, native C execution, and CI pass.
- [x] Evidence distinguishes this standard-library milestone from a lexer,
      parser, self-hosted compiler, native backend, or full Rust independence.

What slice 3 delivers, all in Core, with no Rust library behind it:

- `stdlib.result`: `Failure` (UTF-8, range, duplicate key, path, JSON,
  depth; each with a byte position), `Search`, `Checked`, `BytesResult`,
  `U64Result`, and a stable digest of each.
- `stdlib.bytes`: equality, unsigned lexicographic order, prefix, search,
  copy, append, checked range, decimal rendering.
- `stdlib.text`: UTF-8 validation from Table 3-7 of the Unicode standard,
  JSON escaping.
- `stdlib.vector`: overflow-trapping sum, membership, copy, stable sort,
  lower-bound search.
- `stdlib.ordered_map`: keys in bytewise order, duplicate insert reported
  with its position and never overwriting, missing key as a result.
- `stdlib.path`: only normal relative paths; roots, empty segments, `.`,
  `..`, NUL, `\`, `:` and invalid UTF-8 are refused at the offending byte.
- `stdlib.arena`: a scope tree in two arenas, linked through handles:
  shadowing, duplicates reported with the value kept, lookup to the root; a
  stale handle traps `ARENA_RELEASED`.
- `stdlib.json`: a writer with one spelling per value, and a validator of the
  canonical subset (no whitespace, no duplicate key, `u64` range, standard
  escapes, depth 64).

Toolchain changes the modules needed:

- `argorixc --stdlib <dir>` links stdlib modules; the harness passes it.
- `x.as_slice()` views and `view.slice(a, b)`, checked by `argorix_range`.
- A value `match` arm that leaves by `return` or `break` (regression `g24`).
- Arrays of length 0.
- Writes through a handle (`scope.count += 1`) reach the arena slot; they
  were silently written to a copy before (regression `g25`). A type may point
  to itself through a handle.

Slice 4, the compiler-host boundary:

- `PackageRead` and `BuildWrite` are capabilities that only `argorix_main`
  receives, lent by the driver along with canonical roots and byte budgets.
  Source cannot make one, store one or return one (`CapabilityEscapes`).
  They carry the only IR host effects, `package.read` and `build.write`.
- `stdlib.compiler_host.read` and `write` check the path in Argorix first.
  The C shim checks it again, resolves it with `realpath`, refuses anything
  outside its root (including through symlinks), writes with
  `O_NOFOLLOW`, and charges the budgets.
- Only a program that can hold a capability is built with the shim. The
  harness fails any other binary that imports a file-system function.
- `host_files` covers missing files, directories, traversal, a missing build
  directory and both budgets, and the harness checks the exact build tree it
  leaves. `trap_host_denied` covers a capability the driver did not lend.
  Symlink escapes and unknown flags are covered by a Linux test.

Examples: `example_tokenize.argx` tokenizes a small program with keywords
from an `ordered_map`, and `arena_scopes.argx` builds a symbol tree.

Evidence on this branch: the 14 stdlib fixtures pass with gcc 12.2 and clang
14.0.6, with and without ASan/UBSan (Docker, Debian bookworm). The 42 regression
cases and the 15 runtime cases pass the same matrix, each binary run twice with
identical output. The 550 workspace tests pass on Linux (542
on Windows, which skips the symlink test), and fmt and clippy are clean. The
CI job `stdlib` runs the same matrix with three runs per binary.

Measurements (`bootstrap/ESP-009-measurements.json`, `bootstrap/measure/`):
writing, validating and indexing a JSON object of N members peaks near 2 MB
of resident memory even at N = 16,000. Time, however, is quadratic, about 4.3x
per doubling: `json.validate` compares each key with every earlier one and
`ordered_map.insert` shifts sorted columns. The default budget of 1,000,000
steps covers up to 600-800 members, so a compiler run needs its own budget
from the driver.

Scope of this milestone: a standard library that runs through the stage0
Rust frontend and the transitional C backend. It is not the lexer (ESP-010),
a parser, a self-hosted compiler, a native backend, or independence from
Rust: every fixture here is still checked and emitted by Rust code.
