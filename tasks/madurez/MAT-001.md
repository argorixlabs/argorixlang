1. Inventariar actores: desarrollador, operador, propietario de políticas, agente y verificador externo.
2. Definir tres aplicaciones de referencia: flujo local con herramientas, dos agentes autenticados y recuperación de un flujo tras caída.
3. Fijar plataformas obligatorias, límites soportados y capacidades obligatorias, opcionales y explícitamente excluidas.
4. Crear matriz requisito → tarea → prueba → artefacto; definir qué significa resultado correcto para cada aplicación.
5. Ejecutar las pruebas indicadas; guardar resultados y discrepancias. Corregir y repetir las pruebas afectadas.
6. Actualizar contratos, documentación y esta ficha con evidencias y dependencias restantes. No marcar HECHA antes de verificar todos los criterios.
