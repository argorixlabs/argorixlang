\section{Reproduction Commands}\label{app:reproduce}

From the repository root, use the committed Python environment and scripts:

\begin{lstlisting}
python -m pip install -r paper/requirements.txt
python paper/scripts/analyze_runtime.py
python paper/scripts/render_tables.py
python paper/scripts/generate_figures.py
powershell -File paper/scripts/verify_runtime.ps1
python paper/scripts/check_manuscript.py
python -m pytest paper/tests -q
\end{lstlisting}

The runtime analyzer expects the authorized source artifact directory in the
location documented by its command-line interface; it fails visibly if that
input is absent.  The paper can be built, when a TeX distribution is available,
with:

\begin{lstlisting}
cd paper
pdflatex -interaction=nonstopmode -halt-on-error main.tex
bibtex main
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
\end{lstlisting}

The committed normalized data permit manuscript and figure regeneration
without publishing the original request-directory names or prompt content.
